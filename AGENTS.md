# Repository Guidelines

Veja o `CLAUDE.md`: site estático (index.html, style.css, app.js, calculos.js) no GitHub Pages, dados do ge (Séries A e
B, Parazão e Copa Verde) gravados num Postgres próprio (Hostinger, com PostgREST) por `scripts/sync_supabase.py` via GitHub Actions. Processo DAIA-E em
`.daia/`. Mantenha tudo simples, texto em português, testes em `tests/`, commits com assunto curto e imperativo em
português.
